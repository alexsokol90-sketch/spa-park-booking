# Безопасность и персональные данные

Короткая памятка для проверки репозитория и демо-стенда.

## Секреты
- Ключи (MAX, Telegram, VK, нейросеть, БД, подпись сессий) — только в `.env` на сервере; `.env` в `.gitignore`, в истории git его нет.
- В коде нет паролей и PIN-кодов: пароль владельца берётся из окружения, PIN-коды демо-сотрудников генерируются случайно при заполнении базы и хранятся только как хеш scrypt с солью.
- Если пароль кабинета не задан, вход закрыт (fail-closed), а не открыт.

## Авторизация и доступ
- Кабинет: HTTP Basic поверх HTTPS; владелец или сотрудник по логину и PIN. Роли: управляющий и администратор — всё; мастер — сетка, график, чек-листы; клининг — чек-листы уборки. Права проверяются на сервере (403), а не только скрытием вкладок.
- Защита от перебора: после 10 неверных входов за 15 минут IP блокируется (429).
- Веб-чат гостя: идентификатор сессии выдаёт сервер и подписывает HMAC-SHA256 — подобрать или подменить чужой диалог нельзя.
- Каждое действие гостя проверяется на владение: чужую бронь нельзя отменить, перенести или подтвердить; окно из кнопки перепроверяется (будущее время, часы работы, смена мастера).
- Документация API (`/docs`, `/openapi.json`) в бою отключена.

## Данные в ответах API
- Публичные эндпоинты отдают только каталог и ответы ассистента. Всё с персональными данными — только авторизованным сотрудникам; фильтрация делается в SQL на сервере, а не в браузере.
- Все SQL-запросы параметризованы; поля фильтров рассылок — из белого списка.
- Журнал доступа к ПДн: просмотр гостя, брони, диалога, выгрузка, удаление, рассылка.

## Спам и бюджет нейросети
- Ограничения: 15 сообщений в минуту на гостя (любой канал), 40 запросов в минуту с IP в веб-чат, 8 голосовых в минуту; суточный лимит запросов к модели. При превышении ассистент отвечает без модели.
- Размер сообщения — до 2000 символов, тело запроса — до 12 МБ (Caddy), голос — до 10 МБ.

## Нейросеть
- Модель вызывает только белый список инструментов движка записи; данные чужих гостей ей недоступны.
- Системные правила запрещают раскрывать инструкции и менять роль; телефоны маскируются перед отправкой в модель; аудио голосовых не хранится.

## Инфраструктура
- Сервер и база — в РФ (Timeweb Cloud, Москва). PostgreSQL слушает только localhost; файрвол — только SSH (по ключу, пароли отключены), HTTP и HTTPS.
- Заголовки: HSTS, строгий Content-Security-Policy (только свои скрипты), `frame-ancestors` — встраивание помощника разрешено только на spapark86.ru, `X-Frame-Options` для кабинета, `nosniff`, `Permissions-Policy`.
